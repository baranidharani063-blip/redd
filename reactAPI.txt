🔹 API Integration-க்கு முக்கியமான concepts

நீங்க இந்த 5 விஷயம் தெரிஞ்சுக்கிட்டா போதும்:

1. fetch()

API-க்கு request அனுப்ப.

2. async / await

API response வருவதற்காக wait செய்ய.

3. response.json()

API-ல இருந்து வந்த response-ஐ JSON-ஆ மாற்ற.

4. useEffect()

App/page load ஆனதும் API call செய்ய.

5. useState()

API-ல கிடைத்த data-வை store செய்ய.

🔹 React Native API Integration Example

உங்க Expo project-ல app/index.jsx அல்லது app/index.js இருந்தால் அதில் இதை try பண்ணலாம்.

import React, { useEffect, useState } from "react";
import {
  View,
  Text,
  FlatList,
  StyleSheet,
  ActivityIndicator,
} from "react-native";


export default function Home() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);


  useEffect(() => {
    getUsers();
  }, []);


  const getUsers = async () => {
    try {
      const response = await fetch(
        "https://jsonplaceholder.typicode.com/users"
      );


      const data = await response.json();


      setUsers(data);
    } catch (error) {
      console.log("API Error:", error);
    } finally {
      setLoading(false);
    }
  };


  if (loading) {
    return (
      <View style={styles.center}>
        <ActivityIndicator size="large" />
        <Text>Loading...</Text>
      </View>
    );
  }


  return (
    <View style={styles.container}>
      <Text style={styles.title}>Users List</Text>


      <FlatList
        data={users}
        keyExtractor={(item) => item.id.toString()}
        renderItem={({ item }) => (
          <View style={styles.card}>
            <Text style={styles.name}>{item.name}</Text>
            <Text>{item.email}</Text>
            <Text>{item.phone}</Text>
          </View>
        )}
      />
🔹 இது எப்படி வேலை செய்கிறது?
Step 1 — State create
const [users, setUsers] = useState([]);

Initially:

users = []

API data வந்ததும்:

setUsers(data);

அதாவது API data users-க்குள் store ஆகும்.

Step 2 — useEffect
useEffect(() => {
  getUsers();
}, []);

[] இருப்பதால் component first time open ஆகும்போது getUsers() call ஆகும்.

Step 3 — API call
const response = await fetch(
  "https://jsonplaceholder.typicode.com/users"
);

இது API-க்கு request அனுப்புகிறது.

Step 4 — JSON data
const data = await response.json();

API response-ஐ JSON data-ஆ convert செய்கிறது.

Example:

[
  {
    id: 1,
    name: "Leanne Graham",
    email: "Sincere@april.biz"
  }
]
Step 5 — Data store
setUsers(data);

API data users state-க்குள் வரும்.

Step 6 — Display
<FlatList
  data={users}

users array-ல இருக்கிற ஒவ்வொரு user-ஐ FlatList display செய்யும்.

renderItem={({ item }) => (
  <View>
    <Text>{item.name}</Text>
    <Text>{item.email}</Text>
  </View>
)}

இங்கே:

item.name
item.email
item.phone

API-லிருந்து வந்த values.

🔥 Interview / Viva-க்கு simple definition

API Integration in React Native means connecting our mobile application with a backend/API to fetch, send, update, or delete data.

Example:

React Native
     ↓
   fetch()
     ↓
   REST API
     ↓
   JSON
     ↓
React Native UI
